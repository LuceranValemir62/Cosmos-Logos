# 🌌 Cosmos-Logos

> *"The unexamined universe is not worth living in."*

A living, growing knowledge base at the intersection of **Mathematics**,
**Computer Science**, **Philosophy**, **Statistics**, and **Cosmology**.

This repository is built to **learn deeply, connect ideas across fields,
and share knowledge freely.**

---

## 📂 Repository Map

| Domain | What's Inside | Folder |
|---|---|---|
| 🔢 Mathematics | Algebra, Analysis, Topology, Number Theory | `mathematics/` |
| 💻 Computer Science | Algorithms, Data Structures, ML, Systems | `computer-science/` |
| 🧠 Philosophy | Epistemology, Logic, Metaphysics, Ethics | `philosophy/` |
| 📊 Statistics | Probability, Bayesian Inference, Regression | `statistics/` |
| 🔭 Cosmology | Big Bang, Dark Matter, General Relativity | `cosmology/` |
| 🔗 Connections | Cross-disciplinary essays linking fields | `connections/` |
| 📚 Resources | Book lists, free courses, key papers | `resources/` |

---

## 🎯 Purpose

- **Learn** — Structured notes from textbooks, lectures, and self-study
- **Connect** — Show how math underpins physics, how logic underpins CS,
  how philosophy frames every question
- **Build** — Working code, proofs, and problem solutions
- **Share** — Everything is open, free, and meant to be used
