# 📊 Statistics

Statistics is the science of collecting, analyzing, interpreting, and making decisions from data under uncertainty.

This folder contains notes on probability, statistical inference, data analysis, Bayesian thinking, and computational statistics.

---

## Purpose

The goal of this section is to understand how to reason with data and uncertainty.

Statistics connects deeply with:

- Mathematics
- Computer science
- Cosmology
- Scientific inference
- Machine learning
- Philosophy of evidence

---
